# E-commerce Sales Dashboard

## 📊 Project Overview

This project is an **E-commerce Sales Dashboard** created in Power BI to analyze sales performance, customer activity, and profitability.

The main purpose of the project is to transform raw e-commerce data into an interactive dashboard that helps identify sales patterns and compare performance across cities and product categories.

## 🛠️ Tools Used

* **Power BI**
* **Power Query** — Data Cleaning
* **DAX** — Calculated Measures
* **Excel/CSV Dataset**

## 🧹 Data Cleaning

The raw dataset was prepared before building the dashboard.

The cleaning process included:

* Checking for duplicate records
* Handling missing values
* Correcting data types
* Reviewing inconsistent data
* Preparing clean data for analysis

## 📌 KPIs

The dashboard contains four main KPIs:

* **Total Sales:** 8,971
* **Total Customers:** Number of unique customers
* **Average Order Value (AOV):** Average value per order
* **Profit Margin:** 5.93%

### Profit Margin Calculation

**Profit Margin = Total Profit ÷ Total Sales × 100**

Based on the current dashboard:

**Profit = 532**
**Sales = 8,971**
**Profit Margin ≈ 5.93%**

## 📈 Dashboard Analysis

The dashboard provides different views of the e-commerce data:

### City-wise Sales

A bar chart is used to compare sales performance across different cities.

### Category-wise Sales

A chart is used to compare sales across different product categories.

### Monthly Sales Trend

A line chart shows how sales change over different months and helps identify increases and decreases in sales over time.

## 🎛️ Interactive Filters

The dashboard includes two slicers:

* **City**
* **Category**

These filters allow users to interactively explore the dashboard and analyze specific cities or product categories.

## 💡 Business Purpose

This dashboard can help an e-commerce business:

* Monitor overall sales performance
* Compare sales across cities
* Identify high- and low-performing categories
* Track monthly sales trends
* Monitor profitability
* Explore data using interactive filters

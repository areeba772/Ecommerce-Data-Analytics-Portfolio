# 📊 Retail Sales Data Analysis | Python, Pandas & Matplotlib

## 📌 Project Overview

This project focuses on analyzing retail sales data using Python, Pandas, and Matplotlib. The goal is to clean and prepare the dataset, calculate key performance indicators (KPIs), explore sales trends, and identify top-performing product categories.

The analysis demonstrates how data can be transformed into meaningful insights to support business decision-making.

## 🎯 Project Objectives

- Clean and prepare retail sales data.
- Check missing values and duplicate records.
- Convert the transaction date column into the correct datetime format.
- Calculate important sales and customer KPIs.
- Analyze sales performance by product category.
- Explore monthly sales trends through data visualization.
- Identify patterns that can support business decisions.

## 🛠️ Tools & Technologies

- **Python** — Data analysis
- **Pandas** — Data cleaning, manipulation, grouping, and aggregation
- **Matplotlib** — Data visualization
- **Jupyter Notebook** — Interactive analysis

## 📂 Dataset Overview

The dataset contains the following columns:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## 🧹 Data Cleaning & Preparation

The following data preparation steps were performed:

- Checked the dataset for missing values.
- Checked for duplicate records.
- Reviewed column data types.
- Converted the `Date` column to datetime format.
- Prepared the dataset for further analysis.

## 🔍 Exploratory Data Analysis (EDA)

The analysis included:

- Category-wise sales aggregation using Pandas `groupby()`.
- Monthly sales trend analysis using date-based grouping.
- Calculation of total revenue, average transaction value, units sold, and unique customers.
- Comparison of sales performance across product categories.

## 📈 Data Visualizations

### 1. Sales by Product Category

A bar chart was created using Matplotlib to compare revenue across product categories.

**Key Insight:** Electronics was identified as the highest-revenue product category in the analysis.

### 2. Monthly Sales Trend

A line chart was created to explore changes in sales over time and identify monthly fluctuations.

The visualization helps examine sales patterns and identify months that may require further investigation.
